# Wireframe Generation Pipeline

This system generates low-fidelity wireframes from a screen list using OpenAI for structure and HTML/Playwright for rendering.

## Deliverables Structure

Artifacts are stored in `data/artifacts/{PROJECT_ID}/designs/wireframes/`:
- `/json/` : Validated wireframe JSON definitions.
- `/html/` : Rendered HTML previews (viewable in browser).
- `/images/` : High-resolution PNG screenshots (1440x900).

## Execution Steps

The pipeline is integrated into the `AIDesigner` engine.

### Prerequisites

1.  **Python Environment**: Ensure project dependencies are installed.
2.  **Playwright**: Required for image rendering. 
    ```bash
    pip install playwright
    playwright install chromium
    ```

### Running the Pipeline

You can invoke the pipeline programmatically:

```python
from apps.api.engine.ai_designer import AIDesigner
import asyncio

async def run():
    designer = AIDesigner()
    # Replace with your project ID
    await designer.produce_wireframes("your-project-id")

asyncio.run(run())
```

### Configuration

-   **Wireframe Style**: controlled by `apps/api/engine/wireframe_renderer.py` (CSS).
-   **JSON Structure**: controlled by prompts in `apps/api/engine/ai_designer.py`.

## Rules Implemented

-   **Pure JSON Output**: Generated by LLM, stripped of markdown.
-   **Code-Driven Rendering**: HTML + CSS (Grayscale, 8px grid).
-   **No Hallucinated Images**: All visuals are CSS boxes.
-   **Consistency**: Canvas 1440x900 fixed.
