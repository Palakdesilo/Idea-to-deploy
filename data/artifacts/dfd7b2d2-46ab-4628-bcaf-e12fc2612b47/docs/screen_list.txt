Here is the page list and structural component-based wireframe descriptions for your minimal recipe website:

**Page List:**

1. Home
2. Recipes
3. Search
4. Recipe Details
5. Favorites
6. About

**Wireframes:**

**Home Page:**
* **Header**: Navigation bar with logo, search icon, and navigation links (Recipes, Search, About)
	+ Logo: "Recipe Hub"
	+ Search Icon: magnifying glass
	+ Navigation Links:
		- Recipes
		- Search
		- About
* **Grid**: Featured recipes grid with 3-4 recipe cards per row
	+ Recipe card: title, image, and brief description
	+ Grid layout: responsive, with 2-3 columns on desktop and 1 column on mobile

**Recipes Page:**
* **Header**: Same as Home page header
* **Sidebar**: Filter options (e.g., by course, dietary restriction, cooking time)
	+ Filter options:
		- Course: Appetizer, Main Course, Dessert
		- Dietary Restriction: Vegetarian, Gluten-Free, Dairy-Free
		- Cooking Time: 15 minutes, 30 minutes, 1 hour
* **Grid**: Recipe cards grid with infinite scrolling
	+ Recipe card: title, image, and brief description
	+ Grid layout: responsive, with 2-3 columns on desktop and 1 column on mobile

**Search Page:**
* **Header**: Same as Home page header
* **Form**: Search form with input field and submit button
	+ Input field: placeholder text "Search for recipes"
	+ Submit button: "Search"
* **Grid**: Search results grid with recipe cards
	+ Recipe card: title, image, and brief description

**Recipe Details Page:**
* **Header**: Same as Home page header
* **Content Area**: Recipe details content (title, ingredients, instructions)
	+ Title: Recipe name
	+ Ingredients: list of ingredients with quantities
	+ Instructions: step-by-step cooking instructions
* **Call-to-Action**: "Add to Favorites" or "Print Recipe"

**Favorites Page:**
* **Header**: Same as Home page header
* **Grid**: Favorite recipes grid with recipe cards
	+ Recipe card: title, image, and brief description

**About Page:**
* **Header**: Same as Home page header
* **Content Area**: About us content (text, images)
	+ Text: introduction to the website and its mission
	+ Images: optional images or icons related to the website's theme
