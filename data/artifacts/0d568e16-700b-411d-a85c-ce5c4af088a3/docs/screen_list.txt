## 2. Structural Component-Based Wireframe Descriptions

We'll define some common components first, then describe each page.

### Common Structural Components:

*   **Global Header:**
    *   **Layout:** Horizontal bar at the top of the screen.
    *   **Elements:**
        *   Left: Platform Logo/Name (clickable to Home).
        *   Center: Search Bar (text input, search icon button).
        *   Right: Navigation Icons (Home, Notifications, Messages, Create Post, User Profile/Menu dropdown).
*   **Global Left Sidebar (Optional, for wider screens):**
    *   **Layout:** Vertical bar along the left edge of the screen.
    *   **Elements:**
        *   List of primary navigation links (Home, Explore, Notifications, Messages, Profile, Settings).
        *   Optional: "Create Post" button.
*   **Global Right Sidebar (Optional, for wider screens):**
    *   **Layout:** Vertical bar along the right edge of the screen.
    *   **Elements:**
        *   "Who to Follow" section (list of user cards with "Follow" button).
        *   "Trending Topics" section (list of topic links).
*   **Post Card:**
    *   **Layout:** Self-contained rectangular block.
    *   **Elements:**
        *   User Profile Picture (small circle, clickable).
        *   User Name (text, clickable).
        *   User Handle (text, clickable).
        *   Timestamp (text).
        *   Post Content (text area).
        *   Media Placeholder (rectangular block for image/video).
        *   Action Buttons (Icon: Like, Icon: Comment, Icon: Share).
        *   Optional: Comment section (collapsed by default).
*   **User Card:**
    *   **Layout:** Small rectangular block.
    *   **Elements:**
        *   User Profile Picture (small circle).
        *   User Name (text).
        *   User Handle (text).
        *   Action Button (e.g., "Follow", "Message").
